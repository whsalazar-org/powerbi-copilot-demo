# Power BI Enhancement Workflow

## Phase 1: Intake
- Confirm objective, audience, KPIs, and acceptance criteria.

## Phase 2: Model Impact Review
- Identify impacted tables/relationships/measures.
- Decide whether change is model, DAX, UX, or mixed.

## Phase 3: Implementation
- Apply incremental edits.
- Keep naming and folder conventions consistent.

## Phase 4: Validation
- Reconcile metrics
- Validate context behavior
- Check performance and RLS

## Phase 5: Delivery
- Prepare PR summary, evidence, and follow-up actions.

## Definition of done
- Change meets acceptance criteria
- Validation evidence captured
- Risks and assumptions documented
